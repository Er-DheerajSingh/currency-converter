# Real-Time Currency Converter 💵💱

A responsive, lightweight web application that allows users to instantly convert values between multiple global international currencies using real-time exchange rates.

🛜 **Live Demo:** [Click here to view the live application](https://er-dheerajsingh.github.io/currency-converter/)

---

## 🚀 Key Features
- **Real-Time Data:** Integrates a third-party exchange rate REST API to pull accurate, current conversion rates.
- **Asynchronous Operations:** Utilizes JavaScript Fetch API for seamless, non-blocking data retrieval.
- **Dynamic UI/UX:** Features fluid DOM manipulation to display instant output updates without page reloads.
- **Responsive Design:** Styled with CSS3 Media Queries to ensure flawless operation across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack Used
*   **Frontend:** HTML5, CSS3 (Flexbox/Grid layout)
*   **Logic & Functionality:** Native JavaScript (ES6), Asynchronous Fetch API, JSON Data Parsing
*   **Deployment:** GitHub Pages

---

## 📂 Project Structure
```text
├── index.html     # Structural markup and UI layout

```
